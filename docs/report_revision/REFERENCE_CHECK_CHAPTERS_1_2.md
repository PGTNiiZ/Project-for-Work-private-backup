## ขอบเขตการใช้แหล่งอ้างอิง

- สรุปงานแต่ละชิ้นตามเนื้อหาหรือบทคัดย่อที่ตรวจได้ ไม่อ้างผลเหนือกว่างานเดิมจากตัวเลขคนละข้อมูลหรือคนละวิธีประเมิน
- รายละเอียดโครโมโซม สูตร availability-weighted score และการทำ GA ของโครงงานอ้างอิงโค้ดและ artifact ใน repository ไม่ถือว่าเป็นสูตรที่คัดมาจากงานเหล่านี้
- ค่า 2:1:0.1 และสมมติฐานค่าแรงเป็นข้อกำหนดของโครงงาน ไม่ใช่ผลที่ Elkan หรือแหล่งภายนอกกำหนดให้
- สูตรนับ REVIEW และตัวอย่างคำนวณเป็นการอธิบายที่เขียนขึ้นให้ตรงกับนโยบายของโครงงาน
- ไม่อ้างว่าความเป็นไปได้ของ GA หรือ three-way ER เป็นความใหม่ที่โครงงานเป็นผู้เสนอครั้งแรก
- รายการอ้างอิงเดิม [1]–[8] คงไว้ตามต้นฉบับ การตรวจครั้งนี้ไม่ได้รับรองทุกรายการหรือทุกข้อกล่าวอ้างในบทเดิม
