ไฟล์เดิมที่มีเฉพาะบทที่ 3 ยังคงอยู่สำหรับใช้อ้างอิงเวอร์ชันก่อนหน้า สารบัญพิมพ์เดิมยังไม่รวมรายการใหม่ จึงควรสร้างสารบัญและเลขหน้าทั้งเล่มใหม่เมื่อย้ายเนื้อหาเข้าต้นฉบับจัดเล่มสุดท้าย

### แหล่งแก้ไขและการคอมไพล์

ส่วนเพิ่มเติมแยกเป็น `chapter1_ga_additions.tex`, `chapter2_ga_additions.tex`, `chapter3_ga_additions.tex` และ `references_ga_additions.tex` ไฟล์ชื่อ `*_formatted.tex` เป็นไฟล์หลักสำหรับคอมไพล์แต่ละส่วนด้วย XeLaTeX/Tectonic บนเครื่องที่มีฟอนต์ Thonburi ไฟล์ HTML และ Word สร้างจากเนื้อหาส่วนเพิ่มเติมเดียวกัน สมการใน Word เป็นข้อความแก้ไขได้ ส่วน PDF/LaTeX จัดสมการทางคณิตศาสตร์ไว้แล้ว

### การตรวจไฟล์

คอมไพล์ส่วนเพิ่มเติมสำเร็จ ไม่มีคำเตือนตัวอักษรหายหรือข้อความล้นขอบ ตรวจตัวอย่างหน้าตารางและสมการด้วยภาพ ตรวจโครงสร้าง Word และยืนยันว่าไม่มีคำสั่ง LaTeX หลุดเป็นข้อความ ตรวจ PDF ฉบับรวมว่า content stream ของทุกหน้าต้นฉบับและหน้าที่เพิ่มตรงกับไฟล์ต้นทาง

## สิ่งที่เพิ่ม

1. หัวข้อ 3.6: เหตุผลในการปรับนโยบาย ลำดับจากเกณฑ์เดิมสู่ GA แบบถ่วงน้ำหนัก การเตรียมหลักฐานและ availability mask โครโมโซม 10 ค่า ต้นทุน และขั้นตอนค้นหา
2. หัวข้อ 3.7: บทบาท validation/test การตรึงนโยบาย ฐานเปรียบเทียบ Exact-First และนิยามตัวชี้วัดสามทาง
3. หัวข้อ 3.8: ขั้นตอนดำเนินงาน 9 ขั้น ตั้งแต่ทบทวนระบบเดิมถึงเตรียมผลรายคู่สำหรับ CRM
4. ตารางที่ 3.18–3.20: เปรียบเทียบนโยบาย กลุ่มข้อมูล และผลงานในแต่ละช่วง

เนื้อหานี้เป็นงานต่อยอดของบทที่ 3 ส่วนผลการทดลองในบทที่ 4 และบทสรุปเดิมยังคงตามต้นฉบับ ไม่ได้เปลี่ยนตัวเลขเหล่านั้นให้กลายเป็นผลของ GA รุ่นใหม่ สารบัญเดิมยังอ้างอิงเลขหน้าเดิม ส่วนเพิ่มเติมเข้าถึงได้จากบุ๊กมาร์ก PDF และหัวข้อ 3.6–3.8 เมื่อจัดเล่มฉบับสุดท้ายจากต้นฉบับ Word/LaTeX ควรนำเนื้อหาใหม่เข้าไปแล้วสร้างสารบัญและเลขหน้าทั้งเล่มใหม่
