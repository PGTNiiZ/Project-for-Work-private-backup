# ICSEC 2026 Overleaf Project

## Purpose

This is a self-contained, editable, double-anonymous LaTeX project for the current ICSEC 2026 review manuscript. It is an authoring copy; it does not replace the frozen package in `paper/ieee/`.

## Project files

- Main document: `main.tex`
- Verified bibliography: `references.bib`
- Figure directory: `figures/figure1.pdf`
- Current local preview: 4 pages, verified after self-contained Overleaf-project compilation.

## Topic selection

- Primary ICSEC topic: Evolutionary Computing
- Secondary ICSEC topic: Machine Learning and Deep Learning

## Important boundaries

- Keep the manuscript double-anonymous: do not add author names, affiliations, acknowledgements, identifying URLs, machine paths, or repository-owner identifiers.
- Agentic CRM is application context only. The study does not evaluate a deployed CRM or business outcomes.
- The utility objective is illustrative and scenario-specific; it is not measured economic cost.
- The evaluated data are a transformed LinkSocial derivative. Do not add raw data, profile identifiers, raw decisions, or source data to this project or its upload ZIP.
- Evidence-sensitive prose and values are labelled in `main.tex` comments.

## Build

Overleaf should identify `main.tex` automatically. Use standard pdfLaTeX/BibTeX compilation. See `OVERLEAF_EDITING_GUIDE.md` for upload and editing instructions.
