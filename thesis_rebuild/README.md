## ภาพรวมในหนึ่งนาที

`โปรไฟล์ → ทำความสะอาด → สร้างคู่และ label → แบ่ง entity → คำนวณ features → เทียบ/จูน/ฝึกโมเดล → calibration → เลือก threshold → test → ให้คะแนนคู่ทั้งระบบ → นโยบายตัดสินใจ → รวม entity และวิเคราะห์ผล`

มีหลักฐาน **สองสายที่ต้องระบุชื่อกำกับทุกครั้ง**:

1. **ระบบเดิม / การพัฒนาโมเดล**: โมเดล multimodal 41 features, ผลบน supervised test, และการสร้าง CRM อยู่ใน [รายงานโครงการเดิม](../manuscript/PROJECT_REPORT_TH.md) กับ [ผลประเมินโมเดล](../artifacts/evaluation/current_model_evaluation.json) ใช้เล่าพัฒนาการและระบบที่สร้าง แต่ไม่เอาตัวเลขมาเทียบตรงกับสายที่ 2
2. **การทดลองควบคุมสำหรับข้อสรุปเรื่องนโยบาย**: GB-17/GB-18 และ B0–B3 บนสาม entity-disjoint splits ใช้ [V2R1](../experiments/icsec_final/authoritative_run_v2r1/PROTOCOL_V2R1.md) เป็นหลักฐานตัวเลข และ [ผลวิเคราะห์ฉบับแก้](../paper/reviewer_revision/REVISION_REPORT.md) ช่วยอ่านความหมาย นี่เป็นแกนที่เสนอให้ใช้ตอบว่า GA เพิ่มอะไรจริง

ไฟล์ [tune.csv](../pub_multi/ref/tune.csv) เป็นผลลองค่า training ในสายพัฒนาโมเดล ไม่ใช่ผล B0–B3 ส่วน [บทความฉบับแก้](../paper/reviewer_revision/main.pdf) เป็นงานคนละรูปแบบกับเล่มภาษาไทย; ใช้อ่านวิธีและผลได้ แต่ยังมีประเด็น M5/AI disclosure/ข้อกำหนดการส่งค้างอยู่
